# Biblioteca de Videojuegos

## El proyecto
Este proyecto consiste en el desarrollo de una aplicación web que permitirá a los usuarios **registrar, organizar y gestionar su biblioteca personal de videojuegos**.

Cada usuario podrá:

* Agregar videojuegos a su biblioteca
* Organizar los juegos en distintas colecciones
* Crear colecciones personalizadas según sus preferencias
* Buscar y filtrar juegos por diferentes criterios
* Escribir reseñas y valoraciones sobre los juegos

La aplicación busca ofrecer una experiencia similar a una “biblioteca digital”, enfocada específicamente en videojuegos.

---

## Funcionalidades principales

### Gestión de biblioteca

* Cada usuario contará con una colección por defecto llamada **“Biblioteca”**
* Todos los juegos agregados se almacenarán automáticamente en esta colección

### Colecciones personalizadas

* Creación de colecciones propias (ej: “Pendientes”, “Favoritos”, “Jugados”)
* Posibilidad de agregar un mismo juego a múltiples colecciones

### Búsqueda y filtrado

* Búsqueda de juegos por nombre
* Filtros por:

  * Género
  * Plataforma
  * Otros criterios relevantes

### Reseñas y valoraciones

* Los usuarios podrán:

  * Escribir reseñas
  * Calificar juegos
* Esto permite enriquecer la experiencia y compartir opiniones
